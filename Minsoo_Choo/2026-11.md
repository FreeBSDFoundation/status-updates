## **Reporting Period:** 2026-11-04 - 2026-11-10

### Project: Scheduler Placement Redesign
#### **Overall Status:** On Track
#### **Summary**
ULE's thread placement (affinity, load balancing, etc) aren't ideal and fall behind compared to
other operating systems especially Linux. 4BSD's thread placement policy is almost nonexistant.
Me and three profs (two in scheduling and one in DSA) are planning on new scheduling system that
optimizes CPU efficiency (e.g. minimizing cache misses).
#### **Blockers**
#### **Next Steps**
- Write benchmark orchestrasation program based on existing softwares. This includes existing benchmark suites like
  [mutiliate](https://github.com/rcslab/mutilate) and [filebench](https://github.com/filebench/filebench) and real applications
  like database and web servers measured with hwpmc.
- Benchmark 4BSD changes I have on [my personal branch](https://github.com/mchoo7/freebsd-src/tree/sched)
