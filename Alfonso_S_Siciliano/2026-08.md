### Project: KDE installer dialogs
#### **Overall Status:** Delayed
#### **Summary**

The goal is to allow users to install KDE at the end of the bsdinstall process through a series of dialog-based interfaces. After rebooting, SDDM starts automatically, allowing the user to log in to the graphical environment.

Work in Progress: [repository](https://gitlab.com/alfix/kde-installer-dialogs)

**Last week's work:**

 - Started designing the new bsdinstall-desktop port (and evaluating a possible bsdinstall-gpu port) to move parts of the desktop installation script from bsdinstall to the Ports Collection.

#### **Completed Tasks**

 - The script installs and configures the GPU driver, Xorg, KDE Plasma, and SDDM after a fresh installation.
 - Published a quarterly status report announcement to encourage participation in the Call for Testing.
 - Tested the desktop script with VESA, SCFB, Intel, and AMD graphics.
 - Added a menu for selecting NVIDIA GPUs, tested through the Call for Testing.
 - Implemented GPU auto-detection.
 - Added a VirtualBox option to the GPU menu, including auto-detection and package installation.
 - Added a VMware option to the GPU menu, including auto-detection and package installation.
 - Added an option to install additional NVIDIA GPU tools, tested through the forum.
 - Integrated the script into a generated ISO to install the graphical environment through bsdinstall.
 - Created the desktop.bsdinstall script to install GPU drivers and KDE during a bsdinstall session.
