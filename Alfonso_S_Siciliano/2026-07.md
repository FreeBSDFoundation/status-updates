### Project: Vision Accessibility
#### **Overall Status:** On Track
#### **Summary**

Vision Accessibility is a project focused on improving visual accessibility in FreeBSD by documenting, developing, and integrating assistive technologies for blind and visually impaired users.

Work in progress: Milestone 2.
Create high-contrast themes for the TUI utilities in the FreeBSD BASE system, with an option to select a high-contrast theme directly during OS installation.

**Last week's work**:

 - Improved the high-contrast themes, with a particular focus on the black-and-white theme.
 - Researched Braille displays available for purchase to test Braille display support on real hardware.
 - Contacted a Braille display manufacturer to explore the possibility of establishing a direct collaboration with vendors, including access to technical documentation, potential discounts, and devices for testing.

#### **Completed Tasks**

 - Project presented at the FreeBSD DevSummit in Dublin, Ireland, in 2024: [slides](https://docs.google.com/presentation/d/1LbtygFpcV1PFv9lceW6JANUC3wko9KSsmj9ZlcAAayA).

### Project: KDE installer dialogs
#### **Overall Status:** Delayed
#### **Summary**

The goal is to allow users to install KDE at the end of the bsdinstall process through a series of dialog-based interfaces. After rebooting, SDDM starts automatically, allowing the user to log in to the graphical environment.

Work in Progress: [repository](https://gitlab.com/alfix/kde-installer-dialogs)

**Last week's work:**

 - Discussion and suggestions in the review linked below.

#### **Completed Tasks**

 - The script installs and configures the GPU driver, Xorg, KDE Plasma, and SDDM after a fresh installation.
 - Published a quarterly status report announcement to encourage participation in the Call for Testing.
 - Tested the desktop script with VESA, SCFB, Intel, and AMD graphics.
 - Added a menu for selecting NVIDIA GPUs, tested through the Call for Testing.
 - Implemented GPU auto-detection.
 - Added a VirtualBox option to the GPU menu, including auto-detection and package installation.
 - Added a VMware option to the GPU menu, including auto-detection and package installation.
 - Added an option to install additional NVIDIA GPU tools, tested through the forum.
 - Integrated the script into a generated ISO to install the graphical environment through bsdinstall.
 - Created the desktop.bsdinstall script to install GPU drivers and KDE during a bsdinstall session.

#### **Features Delivered**

 - Review [D56167](https://reviews.freebsd.org/D56167) to add the desktop script to bsdinstall:

A potential solution was presented at BSDCan 2026, but due to licensing issues, it will not be integrated into bsdinstall in the near future.

#### **Next Steps**
