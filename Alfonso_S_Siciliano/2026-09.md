### Project: KDE Installer Dialogs
#### **Overall Status:** Delayed
#### **Summary**

The goal is to allow users to install KDE at the end of the bsdinstall process through a series of dialog-based interfaces.
After rebooting, SDDM starts automatically, allowing the user to log in to the graphical environment.

Work in Progress: [repository](https://gitlab.com/alfix/kde-installer-dialogs).

**This week's work:**

I completed the new ports with flavors and submitted the corresponding PRs to Bugzilla.

New ports:

 - x11/bsdinstall-desktop [PR298402](https://bugs.freebsd.org/bugzilla/show_bug.cgi?id=298402)
    - Base port utilities: bsdinstall-desktop-checks, bsdinstall-desktop-users with menu.
    - Flavor: -audio.

 - graphics/bsdinstall-gpu [PR298413](https://bugs.freebsd.org/bugzilla/show_bug.cgi?id=298413)
    - Base port utility: bsdinstall-gpu with menu.
    - Flavors: -amd, -drm, -intel, -nv304, -nv340, -nv390, -nv470, -nv580, -nv595, -nv610, -nvaddons, -nvoptimus, -radeon, -scfb, -vbox, -vesa, -vmware.

 - x11/bsdinstall-de [PR298442](https://bugs.freebsd.org/bugzilla/show_bug.cgi?id=298442)
    - Base port utility: bsdinstall-de.
    - Flavors: -kde, -wireplumber.

 - x11/bsdinstall-dm [PR298455](https://bugs.freebsd.org/bugzilla/show_bug.cgi?id=298455)
    - Base port utility: bsdinstall-dm with menu.
    - Flavors: -ly, -sddm.

I also completed the rewrite of the bsdinstall script, [desktop.ports](https://gitlab.com/alfix/kde-installer-dialogs/-/blob/main/desktop.ports).

Once the ports are committed, I will start testing the script with an installation ISO and then open a new review to add the "desktop" script to bsdinstall.
I have also marked review D56167 as obsolete, since it covered the previous standalone version of the script, which has now been replaced by the new ports-based implementation.
