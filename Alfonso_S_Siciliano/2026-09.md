## **Reporting Period:** 2026-09-15 - 2026-09-29

### Project: Vision Accessibility
#### **Overall Status:** On Track
#### **Summary**

Vision Accessibility is a project focused on improving visual accessibility in FreeBSD by documenting, developing, and integrating assistive technologies for blind and visually impaired users.

Work in progress: Milestone 2.
Create high-contrast themes for the TUI utilities in the FreeBSD BASE system, with an option to select a high-contrast theme directly during OS installation.

**Last week's work**:

This week, I worked on the next version of bsddialog, mainly focusing on the library's theming support.

The theming code has been improved for better efficiency, and the *bsddialog\_theme.h* API has been extended to allow applications to select or customize a theme.
New files have been created, and existing files have been improved and reorganized.

Sponsored [Commits](https://gitlab.com/alfix/bsddialog/-/commits/main?message=The+FreeBSD+Foundation&committed_after=2026-09-13&committed_before=2026-09-30&page_size=100).

In particular, the library initialization function now uses the new *bsddialog\_init\_auto\_theme()* function, which automatically looks for a user-defined theme at startup.
This means that all utilities in the FreeBSD base system, such as *tzsetup(8)* and *bsdinstall(8)*, as well as ports such as *mgmt-ports/portconfig*, can use a single configuration file to define the theme.
As a result, I do not need to modify each individual utility to provide themes such as high contrast, black and white, or other accessibility-oriented themes.

CHANGELOG:

```
Next Version 1.2

	Improve theming as part of the Vision Accessibility project,
	sponsored by The FreeBSD Foundation.

	Library:
	* add: theme.spinbox.f_color and theme.spinbox.color.
	  Related dialogs: bsddialog_datebox(), bsddialog_calendar(), and
	  bsddoalog_timebox().
	* move: load and save theme file from utility to library:
	   * add: bsddialog_load_theme() API.
	   * add: bsddialog_save_theme() API.
	* add: examples_library/manualtheme.c.
	* add: bsddialog_get_default_theme() API.
	* add: bsddialog_get_auto_theme() API. It automatically detects the
	  theme to use. The precedence order is:
	    1. $BSDDIALOG_THEMEFILE
	    2. $HOME/.bsddialog.conf
	    3. $NO_COLOR
	    4. Default theme: BSDDIALOG_THEME_FLAT if the terminal supports
	       colors, otherwise BSDDIALOG_THEME_BLACKWHITE.
	* change: bsddialog_init() now calls bsddialog_get_auto_theme().
	  Previously, it only selected BSDDIALOG_THEME_FLAT if the terminal
	  supported colors, otherwiseBSDDIALOG_THEME_BLACKWHITE.
	* improve: bsddialog.3 manual.

	Utility:
	* improve theme selection with the following precedence:
	    1. --theme flat|3d|blackwhite
	    2. --load-theme <file>
	    3. --bikeshed
	    4. $BSDDIALOG_COMPATRC=<file>
	    5. $BSDDIALOG_THEMEFILE=<file>
	    6. $HOME/.bsddialog.conf
	    7. $NO_COLOR=<foo>
	    8. default theme: color if the terminal supports colors, otherwise
	       black and white.
	    Items 4-8 are checked only at startup.

	Theme:
	* improve the black and white theme.
	* add new themes in the themes/ directory:
	  - add: no-red (black-blue-cyan-white-yellow.conf)
	  - add: no-yellow-no-blue (black-green-red-white.conf)
	  - add: high-contrast (black-magenta-white-yellow.conf)
```
