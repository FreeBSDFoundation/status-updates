#### **Completed Tasks**
* Moved https://codeberg.org/svmhdvn/dotfiles/src/branch/main/bin/myfbsdbumpport into personal Ports tree fork and split functionality into three components:
  - portsbump: given a list of origins and newversions, generate ready-to-commit final patches for their (DIST|PORT)VERSION bumps and distinfo updates
  - portsci: given a list of origins, perform a series of sanity checks and test suite runs, then generate a final test report
  - forgejo actions workflow: given a Forgejo PR, detect which port origins have changed and run portsci on them, then pass/fail the PR's "checks" status.
