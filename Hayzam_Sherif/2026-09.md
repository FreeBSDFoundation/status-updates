### **Project:** Sylve - GUI for Managing Bhyve, Jails, and More on FreeBSD

#### **Summary/Completed Tasks**

* Tagged and released v0.3.1 (62 commits since v0.3.0) with the full changelog, and updated `sysutils/sylve` in the FreeBSD ports tree through D59480.
* Started Standard Switch VLAN filtering support: the first pass landed, covering the new VLAN schema migration, bridge VLAN handling, and VLAN-aware network attachments for VMs and Jails together with the corresponding UI wiring.
* Hardened Standard Switch interface dependency checks so edits that would leave ports or interfaces in an inconsistent state are caught before they are applied.

* Made VM guest-agent operations fall back to talking to QGA directly when the libvirt sync fails.
* Made cluster joins wait for a fixed Raft index while catching up so joining nodes cannot be promoted from a stale state.
* Improved backup prune error handling.
