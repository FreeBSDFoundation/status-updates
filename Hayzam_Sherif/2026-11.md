# **November - 2026 Status Update - Hayzam Sherif**

## **Reporting Period:** Nov 2, 2026 - Nov 8, 2026

### **Project:** Sylve - GUI for Managing Bhyve, Jails, and More on FreeBSD

#### **Summary/Completed Tasks**

* Landed the Podman/OCI containers backend and UI: a per-pool Podman service and API, stacks with shared folder datasets, a container catalog, resource-tree and guest-picker lists, runtime checks, racct-based CPU/memory limits.
* Reworked cluster security and reliability: mTLS with pinned members, better join keys, typed internal RPC, a single forwarder, an exactly-once FSM, quorum recovery, and leave/join/readdress fixes; migration now uses mTLS (instead of SSH) with catch-up sync and faster imports.
* Backups: added skip(s) for unchanged runs, we now own the snapshot lifecycle, clone on rollback, retain archived generations, validate targets from all voters, and prune/restore faster; updated Zelta sub-tree to v1.2.0.
* Virtualization: added SLIRP user-mode networking as an option for quick and easy networking for VMs.
* Installer and CI: installer images are built in CI and published from tip, with shared Go caches, and a pinned toolchain. The installer now also enables base system `ntpd` and sync by default.
* Cleanup and platform: removed a good amount of dead code, tests, and unused assets; converted repetitive tests to table-driven form; pkg now honours proxy settings and no longer runs package checks during updates; init shows host changes in a review modal while keeping existing PF setups opt-in.

#### **In Progress**

* Preparing the v0.3.2 release with the containers, cluster, backup, and VM networking work.

#### **Next Steps**
