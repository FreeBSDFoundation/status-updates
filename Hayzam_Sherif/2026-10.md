### **Project:** Sylve - GUI for Managing Bhyve, Jails, and More on FreeBSD

#### **Summary/Completed Tasks**

* Merged the FreeBSD + Sylve installer into the tree with unattended installation support: a kiosk installer that installs FreeBSD from pkgbase and Sylve, with guided ZFS/UFS layouts, optional GELI encryption, an offline payload fallback, and hybrid 15-STABLE/16-CURRENT media. ## **Reporting Period:** Oct 5, 2026 - Oct 11, 2026

### **Project:** Sylve - GUI for Managing Bhyve, Jails, and More on FreeBSD

#### **Summary/Completed Tasks**

* Added declarative first-boot provisioning: a single JSON document can set up pools, services, DNS servers, and switches on a node, with per-entry validation and a new docs guide, plus a CLI service startup wait and richer version output.
* Reworked Jail creation: creations are queued as tasks, existing datasets can be imported, and creation progress is now visible in the UI; Jails also expose restart controls, and console reconnection was fixed across lifecycle actions.
* Reworked native iSCSI target support: shared portal listeners, recovery of recorded ports after a failed cold start, bounded extra target configuration, and NVMe namespace identity/mapping fixes backed by updated CI fixtures.
* Added orphaned libvirt configuration recovery for VMs, enforced the `hw.vmm.maxcpu` limit on VM creation, moved CPU pinning to native libvirt XML, and fixed serial/VNC console reconnection.
* Networking: fixed a bridge member IPv6 cleanup race on Standard Switches, fixed the WireGuard stale status and monitor lifecycle, showed named usages for network objects, and cut idle telemetry overhead (fewer forks and redundant Jail state refreshes).
* Platform and UX: tip releases now publish release metadata and preserve download counts, task activity moved into the header with inline replication counts, the downloader switched from `rain` to `anacrolix` and magnet startup was fixed, guest power actions now require confirmation, and npm dependencies and swagger docs were refreshed.
* Started work on a Sylve + FreeBSD Installer ISO with a custom GUI with Firefox kiosk that should be landing with v0.3.2 (next tagged realease).
