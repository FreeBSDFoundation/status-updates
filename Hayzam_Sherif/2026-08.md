# **August - 2026 Status Update — Hayzam Sherif**

## **Reporting Period:** Aug 23, 2026 – Aug 30, 2026

### **Project:** Sylve — GUI for Managing Bhyve, Jails, and More on FreeBSD

#### **Summary/Completed Tasks**

* Tagged and released v0.3.0
* Opened a phabricator review at https://reviews.freebsd.org/D59159
* Addressed few review feedback provided by jrm@

#### **Summary/Completed Tasks**

* Improved MAC address handling for standard switches, we now support supplying a MAC address object directly or even using a ports mac outright.
* Added a persistent global samba config that users can add their own custom text into (appended to [global] block).
* Massively improved cluster leaving/IP change handling for nodes both out of band (OOB) and for a live node/cluster.
* Fixed an issue for ARM64 nodes where U-Boot didn't show up as a usable bootrom for VMs during creation.
* Fixed a bug pertaining to resetting the admin user password from the GUI (validation was too strict just for `admin` not other users wherein changes was being rejected).

#### **In Progress**

* Tag v0.3.1 with all the bugs found/fixed after the v0.3.0 release and MFH as well into last quarterly branch.
* Restart work on Podman/OCI integration
