#### **Overall Status:** On Track
#### **Summary**
As the [CycloneDX SBOM PR](https://github.com/pkgconf/pkgconf/pull/619) matures, I’ve added [sbomtool PR SPDX Lite 3.0.1](https://github.com/pkgconf/pkgconf/pull/632) since it’s also ready. Awaiting review.

I created [PR Add BSD-3-Clause-pos-unchanged](https://github.com/spdx/license-list-XML/pull/3111) for [New license request: BSD-3-Clause-pos-unchanged](https://github.com/spdx/license-list-XML/issues/3081) in the SPDX license database. This is essentially the same as `BSD-2-Clause-pos-unchanged` but includes the `BSD-3-Clause` third clause. The key requirement is that the list of conditions and the following disclaimer must appear in this position and remain unchanged.

Received feedback from srcmgr@ that SPDX-License-Identifiers should follow existing conventions if they’re not for new files. Identifiers should appear in the first license header block.

Updated the `pkg(8)` OSVF PR and converted the VuXML database to OSV JSON once more.
