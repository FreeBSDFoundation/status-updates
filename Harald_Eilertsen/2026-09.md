#### **Open Questions and Discussion**

When submitting PRs to the [upstreaming repo], we want to have someone from the upstream repo review the patches, so that when the time comes to merge with the actual upstream, every patch has been reviewed by relevant people for the code it touches.

However, these upstream reviewers don't count as reviewers for the project (BSD Port) itself, so we also need one or more reviews from people within the project. This will in practice mean me, Greg Lewis or Kurt Miller. A problem occurs when the patches are also authored by us, which is the case for most of them. We can't really review our own patches.

Kurt has reached out to some of the reviewers that have been helping review our patches so far, and asked if they also want to join the project as reviewers. Some have been willing to do so. Something we hope will make it easier to get patches into the repo.

Another thing that could help is if other BSD people would be willing to join as reviewers. This is a bit of a process, but would help by having more people not actively contributing patches themselves to help review our work.
