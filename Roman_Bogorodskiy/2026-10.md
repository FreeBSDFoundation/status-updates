# 10 2026 Status Update for Roman Bogorodskiy

## **Reporting Period:** [2026-10-19] - [2026-10-25]

### Project: libvirt on FreeBSD
#### **Overall Status:** On Track
#### **Summary**

This week I completed testing and merged the TPM device support for the libvirt/bhyve
driver.

The SSD failed in my CI box, which, unfortunately, has no mirroring. Luckily, as almost
all Jenkins configuration for CI runs is hosted on
[github](https://github.com/novel/libvirt-freebsd-ci), I was able to migrate it to a new
disk relatively quickly.

While analyzing test failures on the recovered Jenkins instance, I noticed a test failure
on arm64 that I did not pay attention to previously. Unlike on amd64, on arm64 bhyve
does not install the SIGTERM handler, so the libvirt monitor reacts differently to the
SIGTERM shutdown. This issue in libvirt is now fixed.

I also opened a PR on Forgejo for some bhyve testing: [#75](https://ron-dev.freebsd.org/FreeBSD/src/pulls/75).
I will move that to Phabricator when it's up, I guess.

#### **Completed Tasks**

 * Merged bhyve configuration options listing ([D58419](https://reviews.freebsd.org/D58419)).
 * Merged TPM support for libvirt/bhyve.

#### **Blockers**

Outline of the `bhyve` issues that are either blockers or create
a noticeable inconvenience for development:

 * [resume issues](https://bugs.freebsd.org/bugzilla/show_bug.cgi?id=290735),
 * [virtio-input not working](https://bugs.freebsd.org/bugzilla/show_bug.cgi?id=290364),
 * [arm64 CPU frequency reporting not working](https://bugs.freebsd.org/bugzilla/show_bug.cgi?id=291810).

#### **Next Steps**

 * Keep addressing review comments for the already submitted patches.
 * Work on improving FreeBSD support in QEMU Guest Agent.
 * Start looking into running the TCK test suite against the usermode
   connection (`bhyve:///session`).
