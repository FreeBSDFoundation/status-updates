### Project: libvirt on FreeBSD
#### **Overall Status:** On Track
#### **Summary**

This week I was working mainly on the suspend/resume support implementation
for the libvirt bhyve driver.

The main implementation is ready, and currently I'm testing various corner cases
and polishing the code.

I'm trying to increase test coverage, so I'm extending TCK tests. I have created
merge requests with suspend/resume tests ([#95](https://gitlab.com/libvirt/libvirt-tck/-/merge_requests/95)),
autodestroy test ([#96](https://gitlab.com/libvirt/libvirt-tck/-/merge_requests/96)),
and a not directly related minor infra fix ([#97](https://gitlab.com/libvirt/libvirt-tck/-/merge_requests/97)).
These await review.

Submitted one of the libvirt/bhyve
[fixes](https://patchew.org/Libvirt/20261115102531.41026-1-bogorodskiy@gmail.com/)
separately, which also awaits a review now.

[D61163](https://reviews.freebsd.org/D61163) and [D61266](https://reviews.freebsd.org/D61266)
are still awaiting reviews.

#### **Completed Tasks**

 * `devel/p5-Sys-Virt` was updated to 12.9.0.
 * libvirt/bhyve disk-related improvements and fixes (honor readonly,
   sector size, and nodelete settings, honor the function component of PCI
   addresses, and accept block devices) were merged.
 * libvirt/bhyve fix for SIGKILL terminated VMs was merged.
