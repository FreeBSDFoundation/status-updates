# 09 2026 Status Update for Roman Bogorodskiy

## **Reporting Period:** [2026-09-07] - [2026-09-13]

### Project: libvirt on FreeBSD
#### **Overall Status:** On Track
#### **Summary**

Went through a few review rounds on the `bhyvectl --get-vm-pid` patch
([D59108](https://reviews.freebsd.org/D59108)).
It is now waiting for review of the manpage bits.

Completed and merged VLAN configuration support for libvirt.
While testing it, I found a few incomplete error handling paths
which could leave stale `tap(4)` devices. This is now fixed,
and the fix is merged.

I updated
[devel/py-avocado-framework](https://www.freshports.org/devel/py-avocado-framework/)
to the latest version after verifying that it still works in my CI.

#### **Completed Tasks**
