## **Reporting Period:** [2026-08-03] - [2026-08-09]

### Project: Full CPUID Control for bhyve
#### **Overall Status:** On Track
#### **Summary**
Implemented CPUID contraint override.
The default is to fail if a CPUID constraint is violated, other options are to
warn only or skip the constraints checks completely.

Worked on getting the XSAVE CPUID emulation right.
It seems the only sensible way at this time is to pass through CPUID leaves
0x00000000d indices 2 and up for all features exposed to the guest, which
describe the XSAVE area layout the host CPU uses.
These differ between AMD and Intel, but not so much between different CPU models
from the same vendor, so that shouldn't be a problem in VM migration scenarios.

#### **Next Steps**
- add more CPU models, as well as some from AMD
- Hypervisor signature override
