 ## **Reporting Period:** [2026-07-13] - [2026-07-19]

### Project: Full CPUID Control for bhyve
#### **Overall Status:** On Track
#### **Summary**
Extended the CPUID option parsing to support setting family, model, stepping and maximum supported CPUID functions directly.
Began adding real-world CPU models in addition to architecture levels. The idea is to add a number of preconfigured real-world CPU families and models to serve as a baseline for custom settings when a particular CPU model needs to be emulated.

#### **Next Steps**
- try to optimize the processing of symbolic CPUID feature names (as, don't set each bit individually, but group them internally by function, index, and register)
- improved CPUID feature clearing
- CPUID constraint override
